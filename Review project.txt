=====================================
SECURITY + JWT
==============

SecurityConfig

1. Tắt CSRF
   csrf.disable()

2. Cấu hình CORS
   Cho React localhost:5173 gọi API

3. PermitAll
   /user/auth/**
   /swagger/**
   /uploads/**
   /sinhvien/**

4. authenticated()
   API nào không permit thì bắt login

5. addFilterBefore()
   Gắn JwtFilter vào trước UsernamePasswordAuthenticationFilter

---

JwtFilter

1. Chặn tất cả request đi vào hệ thống

2. Nếu là:
   /user/auth/login

   => cho đi luôn

3. Lấy Authorization Header

   Authorization:
   Bearer xxx

4. Cắt chữ Bearer

5. Lấy token

6. JwtUtil đọc token

   getUsername()

   getRole()

7. Tạo Authentication

   UsernamePasswordAuthenticationToken

8. Nạp vào

   SecurityContextHolder

9. Spring hiểu user đã login

---

JwtUtil

generateToken()

1. Ghi username

2. Ghi role

3. Ghi thời gian tạo

4. Ghi thời gian hết hạn

5. Dùng SECRET ký token

6. Trả token về frontend

---

Logout

1. User logout

2. Lấy token hiện tại

3. Add vào TokenBlackList

4. JwtFilter kiểm tra

   nếu token nằm trong blacklist

   => chặn

UPLOAD HÌNH ẢNH
===============

ImageUploadService

1. Nhận MultipartFile

2. Lấy tên file gốc

   file.getOriginalFilename()

   Ví dụ:

   avatar.jpg

3. Tạo UUID

   UUID.randomUUID()

4. Ghép tên mới

   123abc_avatar.jpg

5. Kiểm tra thư mục uploads

   nếu chưa có

   createDirectories()

6. Tạo đường dẫn

   uploads/123abc_avatar.jpg

7. Copy file

   Files.copy()

8. Trả về tên file

   123abc_avatar.jpg

---

StaticResourceConfig

1. Khai báo

   /uploads/**

2. Trỏ tới

   file:uploads/

3. Cho phép truy cập

   http://localhost:8080/uploads/abc.jpg
